# Ortsrecht Grafschaft Bentheim

Dieses Repository enthält nichtamtliche, maschinenlesbare Markdown-Aufbereitungen öffentlich
bereitgestellter kommunaler Rechtsvorschriften aus dem Landkreis Grafschaft Bentheim.

Die Sammlung unterstützt Rats- und Kreistagsarbeit, Volltextsuche und RAG-Systeme. Das
[Manifest](MANIFEST.md) verlinkt die veröffentlichten Dokumente nach Rechtsträger. Der Aufbau
erfolgt schrittweise; fehlende Einträge bedeuten nicht, dass eine Körperschaft kein Ortsrecht
besitzt. Unsichere PDF-Texte und ungeklärte Fassungen werden zur Prüfung zurückgestellt.

## Quellen und Format

Quellen sind ausschließlich offizielle kommunale Websites. Ortsrechtsübersichten liefern lesbare
Fassungen; Amtsblätter dienen als zusätzliche Änderungshinweise. YAML-Frontmatter enthält eine
stabile Dokument-ID, Rechtsträger, Dokumenttyp, Quelle und Quell-Hash. Ein unbekannter
Gültigkeitsbeginn bleibt leer. Karten und grafische Anlagen bleiben über die Originalquelle
zugänglich. Die Sammlung ist kein vollständiges Amtsblattarchiv.

Maßgeblich ist ausschließlich die amtlich bekanntgemachte Fassung. Die Aufbereitung ersetzt
keine Prüfung der Originalquelle. Aus der technischen Bereitstellung kann keine verbindliche
Aussage über die rechtliche Geltung abgeleitet werden.
